# Pasco Foods Limited - Modern Futuristic Homepage

Recreation of the **Pasco Foods Limited** homepage (`https://www.pascofoods.co.uk/`) built using **React**, **Vite**, **Tailwind CSS**, **Three.js (WebGL)**, and **Framer Motion**.

---

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **3D WebGL**: [Three.js](https://threejs.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Celebration Effects**: [Canvas Confetti](https://github.com/catdad/canvas-confetti)

---

## 💻 How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 3. Build Production Bundle
```bash
npm run build
```
